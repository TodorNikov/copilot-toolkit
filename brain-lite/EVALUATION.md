# Помага ли мозъкът? Проверка на 1 страница

*Does the brain actually help? A one-page check, about 45 minutes. Do it after 3–4 weeks of use, then every 1–2 months.*

Тази проверка отговаря на един въпрос: **дава ли мозъкът по-бързо по-верни отговори, отколкото без него?** Дали файловете са записани правилно, проверява `brain_check.py` при всяко записване. Тук това не се повтаря.

## 1. Подготовка (15 мин)

Напиши **10 въпроса за проекта, на които знаеш верния отговор** от сигурно място: документ, тикет, имейл, човек. Отговорът не трябва да идва от мозъка, иначе проверяваш мозъка със самия него. Запиши откъде знаеш отговора.

Смеси видовете:

| Брой | Вид | Пример |
|---|---|---|
| 3 | текущо състояние | Кога е релийз 2.4? В какъв статус е бъг LOGIN-12? |
| 2 | история | Каква беше датата на релийза преди промяната? |
| 2 | кой / кое | Кой отговаря за модул X? Кой процес се ползва за Y? |
| 1 | нещо, което **не** е записано | Какъв е бюджетът? Вярният отговор е "няма го в мозъка" |
| 1 | нещо, поправяно наскоро | Факт, който си коригирал с "поправи:" |
| 1 | списък | Кои бъгове са отворени? |

## 2. Питаш (20 мин)

**С мозъка:** в папката на мозъка `/clear`, после въпросът. По един въпрос на сесия.

**Без мозъка:** намираш отговора както би го търсил без мозък (Teams, имейл, тикети, памет). Засичаш колко време ти отнема.

## 3. Оценяваш (10 мин)

| # | Въпрос | Верен отговор (откъде) | С мозъка: верен / частично / грешен | Посочи ли правилната страница? | Без мозъка: верен? минути |
|---|---|---|---|---|---|
| 1 | | | | | |
| … | | | | | |
| 10 | | | | | |

После броиш:

- **Помогна:** с мозъка верен, без мозъка грешен или бавен (над 5 мин).
- **Навреди:** с мозъка грешен, а без него щеше да е верен.
- **Тежки грешки** (броят се отделно, дори при висок резултат): измислено име, дата или число; стар факт, даден като текущ; информация от друг проект; "няма го" за нещо, което е записано.

## 4. Решаваш

| Резултат | Какво правиш |
|---|---|
| Помогна ≥ 6, навреди 0, тежки 0 | Продължаваш, както е |
| Има "навреди" или тежка грешка | Отвори страницата, която е използвал. Причината обикновено е една от три: (а) фактът е записан грешно → `поправи: …`; (б) фактът липсва → `запиши: …`; (в) старият факт е над новия → `поправи:` с ясна дата. Ако причината е в поведението на Copilot, добави едно изречение в `AGENTS.md` (Rules). |
| Помогна ≤ навреди | Мозъкът не си струва в тази форма. Виж кои видове въпроси се провалят и записвай повече от тях, или го спри. |

**Време:** минути, спестени седмично (от колоната "без мозъка") минус минути, които отделяш за "запиши" и четене на обобщенията. Ако разликата е отрицателна два пъти подред, опрости или спри.

Запази таблицата като `notes/reports/brain-evaluation-YYYY-MM-DD.md` (`запиши:` + таблицата). Следващия път задай **същите 10 въпроса плюс 2–3 нови**, за да видиш дали има подобрение.

## Граници

10 въпроса са малко. Те показват посока, не доказателство. Един добър резултат не значи, че мозъкът винаги е прав. Затова всеки отговор от него назовава страницата и затова правилото "не измисляй" е в `AGENTS.md`.

*Опростено от по-подробен план за оценка: сравнение с и без памет, двойки "помогна/навреди", тежки грешки отделно от средния резултат, независимо проверени отговори.*
